# Shiny Mega Alakazam mount

Built with `python3 tools/build_mega_alakazam_mount.py` from columns 5–8 of
`assets/mounts/mega_alakazam/source.png`, the shiny half of the supplied sheet.
The original pixel grid, levitation, psychic aura and rider masks match the
normal mount. Runtime sheets use 224px frames; the creature icon is 64px.

The `shiny-mega-alakazam-mount` item unlocks this variant. The
`mega-alakazam-mount-box` in the Aether Gift Store grants normal or shiny.
